Fontes: docs atuais na documentação oficial (Tailwind v4, Next 16.4, shadcn, Radix, motion, Zustand, idb-keyval, MDN). Marcado **[verificar]** o que veio de conhecimento geral e não da doc.

## Tailwind v4
- Breakpoints padrão: `sm` 640, `md` 768, `lg` 1024, `xl` 1280, `2xl` 1536 (`@media (width >= …)`). Tablet retrato (820) = `md`; paisagem (1024/1180) = `lg`; desktop ≥ 1280 = `xl`. **Decisão do projeto: não criar breakpoints custom.**
- Container queries: `@container` (ou nomeado `@container/content`) no pai; `@sm`=384, `@md`=448, `@lg`=512, `@xl`=576, `@2xl`=672, `@3xl`=768, `@4xl`=896, `@5xl`=1024 (px) nos filhos: `@3xl/content:grid-cols-12`.
- `hover:` no v4 já é gerado dentro de `@media (hover: hover)`; cuidado com utilitários não-hover usados para esconder até o hover (`md:opacity-0 group-hover:opacity-100`).
- Variantes por ponteiro: `pointer-coarse:`, `pointer-fine:`, `any-pointer-coarse:` — `class="h-8 pointer-coarse:h-14"`.
- `touch-manipulation`, `touch-pan-x/y`, `touch-none`; unidades `h-dvh`, `min-h-dvh`, `h-svh`; safe area via arbitrário `pb-[calc(env(safe-area-inset-bottom)+0.75rem)]` (só com `viewport-fit=cover`).
- `@custom-variant portrait { @media (orientation: portrait) { @slot; } }` (o Tailwind também tem `portrait:`/`landscape:` nativos **[verificar]**); `@custom-variant standalone { @media (display-mode: standalone) { @slot; } }`.
- `motion-safe:` / `motion-reduce:`.

## Next.js 16.4
- `export const viewport: Viewport = { width: "device-width", initialScale: 1, viewportFit: "cover", interactiveWidget: "resizes-content", themeColor: [{ media: "(prefers-color-scheme: light)", color: "#ffffff" }, { media: "(prefers-color-scheme: dark)", color: "#0a0a0a" }] }` em `app/layout.tsx`. Nunca `maximumScale: 1`/`userScalable: false`.
- `src/app/manifest.ts` exportando `MetadataRoute.Manifest` (`name`, `short_name`, `start_url: "/"`, `display: "standalone"`, `orientation: "any"`, `background_color`, `theme_color`, `icons` 192/512 + `purpose: "maskable"`). Ícones podem ser gerados por Route Handlers com `ImageResponse` de `next/og` (ex.: `app/icon-192/route.tsx`) ou pelas convenções `app/icon.tsx`/`app/apple-icon.tsx`.
- `metadata.appleWebApp = { capable: true, title: "Rotinas", statusBarStyle: "default" }`; `app/apple-icon.(png|tsx)` gera `apple-touch-icon`.
- Service worker: o Next não gera; a doc aponta Serwist para offline completo. **Novo em 16.4:** `experimental: { useOffline: true }` em `next.config.mjs` + `import { useOffline } from "next/offline"` (detecta online/offline, faz polling HEAD, retenta navegação/prefetch/Server Actions). Doc em `node_modules/next/dist/docs/01-app/03-api-reference/05-config/01-next-config-js/useOffline.md`.
- `proxy.ts`: o matcher atual `["/", "/dashboard/:path*"]` não bloqueia manifest/ícones; manter.
- `next/font`: `preload: false` por família para tirar do preload; `display: "swap"` padrão.
- `output: "standalone"` só para Docker.

## shadcn/ui (local, estilo `radix-nova`)
- Sidebar: `isMobile` → Sheet com `--sidebar-width: 18rem` e `[&>button]:hidden`; desktop → `div hidden md:block`, `collapsible="offcanvas"|"icon"|"none"`. Ponto único do breakpoint: `MOBILE_BREAKPOINT` em `src/hooks/use-mobile.ts` (fora de `ui/`); subir para 1024 faz o retrato usar Sheet. `useSidebar()` expõe `setOpen`, `setOpenMobile`, `isMobile`, `state`. `SidebarTrigger` é `icon-sm` (28 px): passar `className` e `aria-label` no uso (o `{...props}` sobrescreve). Não usar `SidebarMenuAction showOnHover` (fica `md:opacity-0` para sempre em touch).
- Sheet: largura por className (`data-[side=right]:w-full sm:max-w-md lg:max-w-lg`); `showCloseButton={false}` para botão próprio.
- Drawer (vaul): `direction="bottom"`; padrão "responsive dialog" (Dialog em `≥768`, Drawer abaixo).
- Tabs sem tratamento touch: envolver em `overflow-x-auto` e aumentar via className no uso. `ScrollArea` + `ScrollBar orientation="horizontal"`.
- Sonner: `<Toaster position="top-center" richColors closeButton duration={8000} />`; o wrapper local repassa `...props` e sobrescreve `toastOptions` (repetir `classNames.toast = "cn-toast"` se passar `toastOptions`).
- Densidade: não há variável de altura de controle; `size="lg"` e `pointer-coarse:*` nos pontos de uso, ou camada global por `data-slot`.

## Radix
- DropdownMenu abre em `pointerdown` (mouse) / click (touch); `modal` default true. Select: `position="popper"` para listas longas.
- Tooltip não abre no toque; nada informativo só em tooltip.
- Dialog/Sheet: `onOpenAutoFocus={(e) => e.preventDefault()}` quando o primeiro focável é input (evita teclado abrindo junto); `onCloseAutoFocus` preventDefault se o trigger saiu da tela.

## motion
- `MotionConfig reducedMotion="user"` já no `MotionProvider`; com reduced motion, transform/layout desligam e opacity continua.
- `layout="position"` só quando só a posição muda; `layoutDependency`; evitar `layout` em listas longas.
- `AnimatePresence initial={false}`; `mode="popLayout"` exige pai com `position`.

## iOS Safari / Android Chrome
- Zoom automático no iOS em campo com `font-size < 16px`; o `Input` local é `text-base md:text-sm` (14 px em tablet). Fix global fora de `@layer`: `@media (pointer: coarse) { input, select, textarea { font-size: max(1rem, 1em); } }`.
- `100vh` → `dvh`; `overscroll-behavior: none` no `html` (já há); `touch-action: manipulation` + `-webkit-touch-callout: none` em botões/links/itens (`@layer base`), sem `user-select: none` em texto de leitura.
- Teclado virtual: `interactive-widget=resizes-content` funciona no Chrome Android, **não** no iOS → `window.visualViewport` (`resize`, `offsetTop/height`) para reposicionar rodapés.
- `inputmode="numeric"|"decimal"`, `enterkeyhint="next|done|go"`, `autocapitalize="characters"` em códigos, `autocomplete="off"` em aparelho compartilhado.
- PWA standalone: `matchMedia("(display-mode: standalone)")`; sem botão voltar no iOS → toda tela com Voltar/Fechar.
- Wake Lock: `await navigator.wakeLock.request("screen")`; liberado ao ocultar; re-adquirir em `visibilitychange`; HTTPS.
- Conectividade: `navigator.onLine` + eventos `online`/`offline`; `useOffline()` do Next.

## Zustand persist + idb-keyval
- `createStore("rotinas-db", "sessao")` para isolar o banco; `clear(store)`.
- `version` + `migrate(persisted, version)` incremental (hoje `version: 2` com reset total → ir para 3 migrando campo a campo).
- `persist.clearStorage()` apaga a chave; no `sair` zerar dados por pessoa e preservar `contexto`.
- `persist` não sincroniza entre abas → `BroadcastChannel("rotinas-sessao")` + `persist.rehydrate()`.
- `createJSONStorage` não valida: validar com Zod em `merge` se for produção.
