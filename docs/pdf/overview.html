Visão geral em poucas páginas

O projeto de relance

Um sistema de rotina que diz a cada pessoa da linha o que fazer agora, registra em poucos toques, detecta o desvio sozinho e entrega à liderança o turno consolidado, sem papel.

Protótipo web na Vercel · piloto na linha Bis 2, posto Embalagem, Loeschpack 2/4/5 · detalhes nos capítulos 01 a 06.

MoSCoW do protótipo

Stack do protótipo

UI

Next.js 16 App Router · React 19 · TypeScript · Tailwind v4 com tokens em @theme · shadcn/ui · lucide · Recharts · react-hook-form + zod

alvos ≥ 56 px · corpo ≥ 16 px · AA

Domínio (TS puro)

RoutineEngine · FormEngine · AlertEngine · KpiEngine (GE, ton/h, MTBF) · ShiftReport · Clock injetável

Vitest · sem dependência de Next

Dados e deploy

Zustand + IndexedDB offline-first atrás de Repository · seed da Bis 2 · Vercel com preview por PR · opcional Neon + Drizzle

portável: standalone + Docker
